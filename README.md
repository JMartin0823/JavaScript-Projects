# 🎬 Movie Search & Watchlist App

A simple and interactive web application that allows users to search for movies and manage a watchlist. The app fetches real-time movie data from the **OMDb API** and provides an intuitive interface
for browsing and saving favorite films.

## 🛠 Features

-   Search for movies\*\* using keywords.
-   View movie details\*\* including title, year, genre, and rating.
-   Save movies to a watchlist\*\* for later viewing.
-   Remove movies from the watchlist when no longer needed.
-   Persistent storage using `localStorage`, so the watchlist remains saved even after closing the browser.
-   Modern and responsive design\*\* optimized for all screen sizes.

## 🚀 Live Demo

[Click here to view the deployed project.](https://jmle-moviewatchlist.netlify.app/)

## 📂 Project Structure

-   **`index.html`** – The main page for searching movies.
-   **`watchlist.html`** – The saved movies page (watchlist).
-   **`index.js`** – Handles searching, fetching movie data, and saving movies to `localStorage`.
-   **`saved.js`** – Manages displaying and removing movies from the watchlist.
-   **`index.css`** – Styles the application with a clean, modern design.

## 🧰 Technologies Used

-   **HTML5**
-   **CSS3**
-   **JavaScript (ES6)**
-   **OMDb API** (for fetching movie data)
-   **LocalStorage** (for persisting the watchlist)
