# 🍜 Asian Food Ordering App  

An interactive **restaurant ordering system** that allows users to select and customize their orders from an Asian cuisine menu. This project showcases JavaScript's capabilities in **handling dynamic UI updates, managing cart functionality, and processing checkout interactions**.

## 🛠 Features  

- **Dynamic Menu Display** – Items are loaded from a structured data file.  
- **Interactive Ordering System** – Users can add and remove items from their cart.  
- **Real-time Order Summary** – Automatically updates total price and selected items.  
- **Checkout Process** – Users can enter their name and confirm the order.  
- **Responsive Design** – Adapts to different screen sizes for mobile and desktop use.  

## 🚀 Live Demo  

[Click here to view the deployed project.](https://orderingapp-jmle.netlify.app/)

## 📂 Project Structure  

- **HTML**: Provides the core structure for the restaurant interface.  
- **CSS**: Styles the layout, making it **clean, modern, and fully responsive**.  
- **JavaScript**: Implements **menu rendering, cart management, checkout logic, and UI updates**.  
- **Data File**: Stores menu items dynamically for easy expansion and modification.  

## 🧰 Technologies Used  

- **HTML5**  
- **CSS3**  
- **JavaScript (ES6+)**
