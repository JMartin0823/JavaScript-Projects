# 🎨 Color Palette Generator

A simple and interactive application that allows users to generate color palettes based on a selected color and mode. This project demonstrates dynamic UI updates using JavaScript and fetches data
from an external API to provide users with various color scheme options.

## 🛠 Features

-   Select a base color using a color picker.
-   Choose a color scheme mode from multiple options.
-   Generate a palette of six colors based on user selection.
-   Responsive design for a smooth user experience.

## 🚀 Live Demo

[Click here to view the deployed project.](https://jmle-colorpalette-generator.netlify.app/)

## 📂 Project Structure

-   **HTML**: Defines the structure of the application.
-   **CSS**: Styles the interface with a clean and modern design.
-   **JavaScript**: Implements interactivity and API integration.

## 🧰 Technologies Used

-   **HTML5**
-   **CSS3**
-   **JavaScript (ES6)**
-   **The Color API** (for generating color palettes)
